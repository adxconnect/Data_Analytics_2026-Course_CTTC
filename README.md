### 📋 &nbsp; About the Programme

This repository documents the complete journey through the **Entrepreneurship-cum-Skill Development Programme (E-SDP)** on **Data Analytics**, organized by **MSME-TC CTTC, Bhubaneswar** at **Dr. B.C. Roy Engineering College, Durgapur** from **15th January 2026 to 26th February 2026**.

The programme covered **Python Programming**, **Machine Learning (Naive Bayes & SVM)**, **Excel Analytics**, **Tableau**, and **Power BI** — culminating in a capstone **Global AI Jobs Dashboard** project built with real-world Kaggle data.

</td>
